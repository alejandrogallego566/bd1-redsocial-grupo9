# bd1-redsocial-grupo9

## Nombre del proyecto
Diseño de base de datos para una red social estudiantil ("Pascualina") - Base de Datos I.

## Integrantes del equipo
- Andry Zharick Mariño Moreno
- Alejandro Gallego Velásquez

## Descripción del caso
La idea es diseñar la base de datos de una red social pensada solo para estudiantes, donde puedan crear su perfil, seguir a otros compañeros, publicar cosas (preguntas, recursos, noticias, memes), mostrar sus intereses y habilidades, crear o unirse a comunidades (grupos de estudio, hackatones, clubes) y programar o participar en actividades y eventos.

- En la Tarea 1 se hizo el modelo conceptual (Entidad-Relación) de esa base de datos.
- En la Tarea 2 se hizo el modelo lógico, aplicando la normalización hasta la tercera forma normal (1FN, 2FN y 3FN), con su diccionario de datos.

## Estructura del repositorio
- Tarea1/Informe/ -> Informe en PDF del modelo conceptual, con entidades, atributos, relaciones y conclusiones
- Tarea1/Video/ -> Enlace al video de sustentación de la Tarea 1 en YouTube
- Tarea2/Informe/ -> Informe en PDF del modelo lógico, con normalización, diccionario de datos, relaciones, diagrama y conclusiones
- Tarea2/Video/ -> Enlace al video de sustentación de la Tarea 2 en YouTube
