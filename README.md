# bd1-redsocial-grupo9

## Nombre del proyecto
Diseño e implementación de la base de datos de una red social estudiantil ("Pascualina") - Base de Datos I.

## Integrantes del equipo
- Andry Zharick Mariño Moreno
- Alejandro Gallego Velásquez

## Descripción del caso
La idea es diseñar la base de datos de una red social pensada solo para estudiantes, donde puedan crear su perfil, seguir a otros compañeros, publicar cosas (preguntas, recursos, noticias, memes), mostrar sus intereses y habilidades, crear o unirse a comunidades (grupos de estudio, hackatones, clubes) y programar o participar en actividades y eventos.

- En la Tarea 1 se hizo el modelo conceptual (Entidad-Relación).
- En la Tarea 2 se hizo el modelo lógico, con la normalización hasta la tercera forma normal y su diccionario de datos.
- En la Tarea 3 se implementó el modelo físico en PostgreSQL (script DDL con las 16 tablas).
- En la Tarea 4 se implementó el modelo en tres SGBD (PostgreSQL, MySQL y SQL Server), con campos JSON para datos semiestructurados (Big Data e IoT), un diccionario genérico actualizado y un diccionario físico por cada motor.
