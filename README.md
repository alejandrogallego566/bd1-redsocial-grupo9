# bd1-redsocial-grupo9

## Nombre del proyecto
Diseño de base de datos para una red social estudiantil ("Pascualina") - Tarea 1, Base de Datos I.

## Integrantes del equipo
- Andry Zharick Mariño Moreno
- Alejandro Gallego Velásquez

## Descripción del caso
La idea es diseñar la base de datos de una red social pensada solo para estudiantes, donde puedan crear su perfil, seguir a otros compañeros, publicar cosas (preguntas, recursos, noticias, memes), mostrar sus intereses y habilidades, crear o unirse a comunidades (grupos de estudio, hackatones, clubes) y programar o participar en actividades y eventos. En esta primera tarea se hizo el modelo conceptual (Entidad-Relación) de esa base de datos.

## Estructura del repositorio
- Tarea1/Informe/ -> Informe en PDF con el paso a paso, entidades, atributos, relaciones y conclusiones
- Tarea1/Video/ -> Enlace al video de sustentación en YouTube
