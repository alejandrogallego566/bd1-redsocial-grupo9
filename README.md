# bd1-redsocial-grupo9

## Nombre del proyecto
Diseño e implementación de la base de datos de una red social estudiantil ("Pascualina") - Base de Datos I.

## Integrantes del equipo
- Andry Zharick Mariño Moreno
- Alejandro Gallego Velásquez

## Descripción del caso
La idea es diseñar la base de datos de una red social pensada solo para estudiantes, donde puedan crear su perfil, seguir a otros compañeros, publicar cosas (preguntas, recursos, noticias, memes), mostrar sus intereses y habilidades, crear o unirse a comunidades (grupos de estudio, hackatones, clubes) y programar o participar en actividades y eventos.

- En la Tarea 1 se hizo el modelo conceptual (Entidad-Relación).
- En la Tarea 2 se hizo el modelo lógico, con la normalización hasta la tercera forma normal y su diccionario de datos.
- En la Tarea 3 se implementó el modelo físico en PostgreSQL (script DDL con las 16 tablas).
- En la Tarea 4 se implementó el modelo en tres SGBD (PostgreSQL, MySQL y SQL Server), con campos JSON y diccionarios de datos.
- En la Tarea 5 se hicieron 6 consultas DML y 4 vistas en PostgreSQL.
- En la Tarea 6 se diseñó una arquitectura híbrida en PostgreSQL: las tablas relacionales más campos JSONB y tablas para datos de sensores IoT (con particiones e índices GIN), con 6 consultas sobre datos semiestructurados.

## Estructura del repositorio
- Tarea1/ y Tarea2/ -> Modelo conceptual y modelo lógico (informe y video)
- Tarea3/ -> Modelo físico en PostgreSQL (script, informe y video)
- Tarea4/ -> Tres SGBD: diccionarios, scripts DDL, informe y video
- Tarea5/ -> Consultas DML y vistas (scripts, informe y video)
- Tarea6/scripts/ -> Datos de ejemplo, borradores de cada integrante y script final (DDL y DML) de la arquitectura híbrida
- Tarea6/informe/ -> Informe técnico en PDF
- Tarea6/video/ -> Enlace al video de sustentación en YouTube
